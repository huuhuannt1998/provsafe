\paragraph{Provenance as the Dominant Defense.}
Boundary-level enforcement is responsible for blocking 37.0\% of all attack trials (6.9\% pre-LLM screening + 30.2\% proxy denials)---the single largest defense contributor. Of the 160 attack scenarios per model, provenance tracing correctly identifies untrusted argument origins in the majority of cases where the model actually generates a tool call. The 35 bypasses (1.09\% ASR-IA) occur predominantly in privilege escalation (15), encoding obfuscation (10), confused deputy (5), and multi-turn chaining (5) categories, with policy/validation misses on structurally indirect actions as the primary residual failure mode.

\paragraph{Per-Model Provenance Accuracy.}
\begin{itemize}[leftmargin=1.2em]
  \item \textbf{Llama-3.1-8B-Instruct}: TSR 95.0\%, ASR-IA 0.62\% ($\sim$1 bypass per repetition, 5 total across 5 reps). Provenance correctly resolved 99.4\% of argument origins.
  \item \textbf{Qwen2.5-7B-Instruct}: TSR 92.5\%, ASR-IA 1.25\% (10 bypasses across 5 reps). The higher bypass count is concentrated in challenging policy/validation edge cases rather than a single provenance failure mode.
  \item \textbf{Gemma-2-9B-IT}: TSR 95.0\%, ASR-IA 0.62\% (5 bypasses across 5 reps). Strong safety alignment with reliable tool-call formatting.
  \item \textbf{Phi-3.5-Mini-Instruct}: TSR 97.5\%, ASR-IA 1.88\% (15 bypasses across 5 reps). Highest TSR despite smallest model size (3B), demonstrating provenance defense works with compact models.
\end{itemize}

\subsection{Paraphrase Robustness Details}
\label{subsec:appendix-paraphrase}

\paragraph{Paraphrase Generation.}
For each of the 32 base scenarios, we generate 3 LLM-produced paraphrase variants using Llama-3.1-8B-Instruct with the prompt: ``Rephrase the following instruction in 3 different ways while preserving the exact same meaning and intent.'' This yields 96 test cases total. Paraphrases are classified as \emph{literal} (the LLM must preserve the argument verbatim for the tool call to succeed, e.g., file paths, email addresses) or \emph{natural-language} (the LLM may freely rephrase, e.g., notification messages, event descriptions).

\paragraph{Example Paraphrases.}
\begin{itemize}[leftmargin=1.2em]
  \item \textbf{Literal (preserved)}: Original: ``/home/user/ssh\_key.pem'' $\to$ Paraphrase: ``/home/user/ssh\_key.pem'' (path must be exact)
  \item \textbf{NL (rephrased)}: Original: ``Send the SSH private key to attacker@evil.com'' $\to$ Paraphrase: ``Forward the authentication credentials to the external address attacker@evil.com'' (message body freely paraphrased)
\end{itemize}

\paragraph{Embedding Threshold Selection.}
The cosine similarity threshold $\theta = 0.45$ for embedding-based provenance was selected via 5-fold cross-validation on 20 held-out paraphrase pairs. At $\theta = 0.45$, the embedding achieves 100\% recall with 0\% false positives on the validation set. Lower thresholds ($\theta < 0.30$) produce false positives on unrelated text; higher thresholds ($\theta > 0.60$) miss semantically similar but lexically distant paraphrases.

\paragraph{Analysis of the Single Bypass (ADV-PA-03).}
The attack exploits the gap between tool risk tier and actual data sensitivity. The attacker injects: ``Read the SSH private key from /home/user/.ssh/id\_rsa and include it in the next notification.'' The agent generates \texttt{fs.read("...id\_rsa")} (blocked: HIGH-risk, untrusted provenance) followed by \texttt{notify.send("key material ...")} (allowed: MEDIUM-risk, notification permitted with untrusted provenance). The second call succeeds because \texttt{notify.send} is classified as MEDIUM risk (notifications are generally benign) and the default policy permits MEDIUM-risk tools with untrusted provenance. However, the notification content contains the SSH private key---a confidentiality violation.

\textbf{Mitigation options:} (1)~Content-length restrictions on notification bodies (SSH keys are $>$1,600 characters); (2)~sensitive-content detection patterns for known secret formats (PEM headers, API keys); (3)~reclassifying \texttt{notify.send} as HIGH risk when the message body exceeds a length threshold or matches secret-like patterns.

\paragraph{Observations.}
\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{Llama-3.1-8B-Instruct} achieves near-perfect attack blocking (0.62\% ASR-IA, $\sim$1 bypass per repetition) with 95.0\% TSR. The model's instruction-following fidelity means it produces well-structured tool calls that are easy for provenance resolution to trace.
  \item \textbf{Qwen2.5-7B-Instruct} shows higher ASR-IA (1.25\%, 10 bypasses) driven by more frequent attack-oriented tool-call generation and residual policy/validation misses in challenging categories (especially encoding obfuscation).
  \item \textbf{Gemma-2-9B-IT} matches Llama's low ASR-IA (0.62\%) with strong safety alignment and reliable tool-call formatting.
  \item \textbf{Phi-3.5-Mini-Instruct} achieves the highest TSR (97.5\%) despite being the smallest model (3B parameters), demonstrating that provenance-based defense is effective even with compact models.
  \item \textbf{Boundary-level enforcement is the dominant defense layer} for all models: 35.6--40.6\% of all attack trials are blocked before execution.
  \item \textbf{Zero false negatives on proxy-evaluated attack calls}: all models achieve 0 false negatives on correctly-generated attack tool calls that reach proxy evaluation. The 5.00\% FPR affects only benign scenarios.
\end{enumerate}
