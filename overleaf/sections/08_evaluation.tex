\section{Evaluation}
\label{sec:eval}

\subsection{Research Questions}

We address nine research questions: \textbf{RQ1:} How effective is \sys{} at blocking attacks compared to baselines? \textbf{RQ2:} What is each component's contribution? \textbf{RQ3:} What usability trade-offs arise? \textbf{RQ4:} How robust are results across models? \textbf{RQ5:} Are \sys{}'s provenance decisions accurate? \textbf{RQ6:} How robust is \sys{} against adaptive paraphrase attacks? \textbf{RQ7:} Can an adaptive adversary with white-box knowledge bypass \sys{}? \textbf{RQ8:} Does \sys{} generalize to an external benchmark with unseen tool ecosystems? \textbf{RQ9:} How robust is the argument decoder against encoded and obfuscated payloads?

\subsection{Methodology}
\label{subsec:methodology}

We evaluate 212 scenarios (172 attacks across 9 categories, 40 benign tasks) on five models from five vendor families: four local models (Llama-3.1-8B, Qwen2.5-7B, Gemma-2-9B, Phi-3.5-Mini; Q4\_K\_M quantized via LM Studio on Apple M4 Pro) and GPT-4o-mini~\cite{openai-gpt4omini} via API. Five configurations isolate defense layers: \textbf{No Defense} (unfiltered); \textbf{Pattern Filter} (47-rule Rebuff-derived~\cite{rebuff-defense} regex); \textbf{Policy-Only} (\sys{} with provenance disabled); \textbf{Taint-Everything} (all arguments untrusted---security upper-bound); and \textbf{\sys{} (Full)}. Each configuration runs five repetitions per scenario-model pair with unique cryptographic seeds,\footnote{Seeds: SHA-256(scenario $\|$ system $\|$ model $\|$ rep); $T \in \{0.0, 0.10, 0.15, 0.20, 0.20\}$.} yielding \textbf{26{,}500 total trials} (16{,}960 primary + 4{,}240 Taint-Everything + 5{,}300 GPT-4o-mini). A call is ``dangerous'' if it matches deterministic patterns (delete, write to absolute path, unlock, out-of-range temperature). Metrics: ASR-IA, TSR, FPR, and ASR-C (confidentiality, InjecAgent DS subset). Confidence intervals are 95\% Wilson-score~\cite{wilson1927probable}; pairwise significance uses Fisher exact tests with Bonferroni correction~\cite{cohen1988statistical}.

Tables~\ref{tab:main_results}--\ref{tab:baseline_comparison} present the main results. \sys{} achieves \textbf{1.02\% $\pm$ 0.34 ASR-IA} with \textbf{95.00\% $\pm$ 1.52 TSR} across 4{,}240 trials---a 24$\times$ reduction versus No Defense and 7$\times$ versus Pattern Filter. Per-category results (Appendix~\ref{sec:appendix-categories}) show encoding obfuscation (2.78\%) and privilege escalation (3.75\%) as the primary residual categories. All 40 false positives (5.0\% FPR) trace to 3 benign scenarios where models map non-temperature commands to \texttt{set\_temperature()}, triggering range checks; the DAG correctly classifies all arguments as trusted.

\subsection{RQ2--3, RQ5: Components, Usability, Provenance Accuracy}

Boundary enforcement (23.5\%) and model refusal (27.2\%) are complementary layers (Table~\ref{tab:main_results}). The proxy denials represent cases where the LLM \emph{did} generate a dangerous tool call but provenance traced arguments to untrusted sources---precisely the gap Policy-Only cannot fill. In instrumented trials, Stage~1 (substring) resolves 100\% of argument resolutions; Stages~2--3 are validated in RQ6. All proxy-blocked evaluations contain arguments tracing to untrusted DAG nodes (zero false denials). Residual bypasses stem from encoding obfuscation and indirect chaining, not provenance failures.

\sys{} achieves 95.00\% TSR with 5.00\% FPR. All false positives arise from policy rules, not provenance---the DAG correctly labels all benign arguments as trusted. Taint-Everything achieves 0.00\% ASR but collapses TSR to 9.00\% (91\% FPR), confirming \sys{}'s core claim: provenance \emph{granularity} separates effective security from unusable security---10$\times$ better usability at $<$1.1pp marginal security cost.

We evaluate paraphrase evasion by disabling Stages~2--3 and testing 96 paraphrase variants, classified as \emph{literal} (paths, emails---LLM preserves verbatim) or \emph{natural-language} (messages, titles---LLM may freely rephrase). Substring-only provenance blocks 93.3\% of literal-argument attacks but only 7.8\% of NL arguments (52.1\% overall paraphrase ASR). The failure is structural: the LLM paraphrases injected content into semantically equivalent but textually different arguments that substring matching cannot link to the untrusted source.

\textbf{Embedding-enhanced provenance} (all-MiniLM-L6-v2, $\theta = 0.45$, $<$5\,ms per comparison) restores \textbf{100\% recall} on both literal and NL arguments (Table~\ref{tab:paraphrase}), reducing paraphrase ASR to \textbf{0.0\%}.

\subsection{RQ7: Provenance Against Adaptive Adversaries}
\label{subsec:adaptive}

We evaluate \sys{}'s resilience against a white-box adversary with full knowledge of the architecture, provenance tracking, policy rules, and embedding model. We craft 50 attack scenarios across five bypass strategies (provenance laundering, policy-aware evasion, embedding evasion, TOCTOU amplification, multi-vector chaining) plus 10 benign controls, evaluated with Llama-3.1-8B over 3 repetitions (180 total LLM trials). Full per-category results appear in Table~\ref{tab:adaptive} (Appendix~\ref{sec:appendix-results}).

\sys{} blocks \textbf{all 50 attacks} (0\% ASR, 95\% CI [0.0\%, 2.5\%]) with 0\% FP. Three findings emerge: (1)~provenance laundering fails by design---the lattice meet preserves taint through intermediate derivation, so no sequence of legitimate calls can shed the $\bot$ label; (2)~embedding evasion and TOCTOU attacks are blocked by complementary layers (embedding similarity and persistent DAG labels); (3)~the provenance DAG correctly identifies untrusted arguments in every case---residual risk is a policy configuration choice, not a provenance failure.

\subsection{RQ8: External Benchmark (InjecAgent)}
\label{subsec:injecagent}

We evaluate on InjecAgent~\cite{injecagent2024}, an independent benchmark of 1,054 indirect prompt-injection cases across 17 user tools and 63 attacker tools (Zhan et al., ACL 2024). We adapt InjecAgent's two-turn interaction: the tool response containing the injection is added to the DAG as UNTRUSTED; any attacker-tool call is intercepted. All five systems are evaluated across four local models and GPT-4o-mini (3 reps each, \textbf{79{,}050 total trials}).

\paragraph{Results.}
The defense hierarchy is clear (Table~\ref{tab:injecagent}): No Defense $\to$ Pattern Filter $\to$ Policy-Only $\to$ \sys{} $\to$ Taint-Everything. \sys{} achieves \textbf{6.1$\times$} reduction versus No Defense and \textbf{2.9$\times$} versus Policy-Only. GPT-4o-mini (15{,}810 trials) shows lower absolute ASR---No Defense 2.53\%, \sys{} 1.17\%---with \sys{} still the lowest.

Policy-Only's failure mode is revealing: at 12.34\% overall ASR, it still permits 21.7\% of Data Stealing attacks because exfiltration tools (\texttt{GmailSendEmail}, \texttt{BankManagerTransferFunds}) are MEDIUM risk. \sys{} closes this gap via provenance: tracing arguments to the untrusted tool response regardless of tool risk tier. \sys{} achieves \textbf{0\% ASR on all Direct Harm categories} and \textbf{ASR-C = 8.2\%} on Data Stealing (vs.\ 31.3\% No Defense)---a 3.8$\times$ reduction. The residual stems from MEDIUM-risk exfiltration channels; a single policy rule would close this gap. \subsection{RQ9: Encoding Robustness}
\label{subsec:encoding}

We test 36 encoding vectors across four categories (single, double/chained, mixed, novel/adversarial including Cyrillic homoglyphs and zero-width characters). The iterative multi-pass decoder achieves \textbf{36/36 (100\%)} detection (vs.\ 24/36 for single-pass). End-to-end with Llama-3.1-8B (108 trials), \textbf{zero dangerous tool calls} are produced---encoded payloads fail to elicit model compliance. The 2.78\% residual on the primary benchmark reflects model-level encoding compliance, not decoder limitations (Appendix~\ref{sec:appendix-encoding}).
