\section{Threat Model}
\label{sec:threat}

\subsection{System Model}

We consider a smart home with an LLM agent that executes user commands by calling registered tools (file system, calendar, notification, email, device control). The agent reads both \emph{trusted} input (user commands, system prompts) and \emph{untrusted} content (device names, file contents, calendar events, notification messages) during execution.

\subsection{Attacker Capabilities}

The attacker (1)~controls untrusted content sources (can set device names, create events, write files the agent may read) but cannot modify system prompts or inject into user commands directly; (2)~knows the agent's tool set and general prompt structure; (3)~can craft sophisticated natural-language injections including jailbreaks, role-play, and encoding obfuscation; (4)~cannot exploit model-level vulnerabilities (gradient-based attacks on weights); (5)~has no physical access to the home or network.

\subsection{Attack Taxonomy}

We categorize attacks into 8 categories:
\textbf{A1:} Direct injection (malicious commands in user-facing input);
\textbf{A2:} Device-state injection (malicious device names/states);
\textbf{A3:} File-content injection (injected instructions in files);
\textbf{A4:} Multi-turn chaining (cross-turn injection chains);
\textbf{A5:} Encoding obfuscation (Base64, URL, Unicode, ROT13);
\textbf{A6:} Role-play jailbreak (``You are DAN\ldots'');
\textbf{A7:} Confused deputy (exploiting capability confusion);
\textbf{A8:} Privilege escalation (progressive unauthorized access).

\subsection{Security Goals and Enforcement Properties}

A defense must ensure confidentiality (prevent data exfiltration), integrity (prevent unauthorized modifications), availability (prevent denial-of-service), least privilege (tool calls justified only by trusted instructions), and usability (minimize false positives and confirmation burden).

\sys{} provides three enforcement properties: \textbf{Complete mediation}---every tool call passes through the enforcement proxy; \textbf{Policy determinism}---identical inputs yield identical decisions; \textbf{Conservative trust propagation}---if any ancestor node is UNTRUSTED, the derived node is UNTRUSTED ($T(v) = \textsf{UNTRUSTED}$ if $\exists u_i \in \text{ancestors}(v): T(u_i) = \textsf{UNTRUSTED}$). These are enforcement correctness guarantees contingent on provenance resolution accuracy; substring matching achieves 95\% detection on our benchmark but drops to 65\% against adaptive paraphrase attacks (Section~\ref{subsec:paraphrase}).
