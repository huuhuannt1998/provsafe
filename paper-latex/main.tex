\begin{abstract}
Large language models (LLMs) are being rapidly deployed as autonomous agents capable of controlling
smart home devices, managing files, and accessing sensitive data through natural language interfaces.
However, these \emph{tool-using LLM agents} are fundamentally vulnerable to \emph{prompt injection attacks},
where adversaries embed malicious instructions in external content---device names, calendar events, file
contents---that the agent reads during task execution. When the LLM processes this attacker-controlled data
alongside legitimate user commands, it cannot reliably distinguish instructions from data, leading to
unauthorized tool invocations such as data exfiltration, file deletion, or privilege escalation.

Existing defenses are inadequate: pattern-based filtering fails against semantic obfuscation and encoding
attacks, dual-LLM architectures double inference cost while remaining vulnerable to sophisticated injections,
and output validation lacks the context to distinguish benign from malicious tool calls. The fundamental
challenge is that security decisions cannot be made reliably at the prompt level where LLMs operate.

We present \sys{}, a provenance-verified capability sandboxing framework that enforces security at the
\emph{tool-call boundary} rather than the prompt level. \sys{} maintains a directed acyclic graph tracking
the provenance of every piece of information the agent processes, labeling data as trusted (from authenticated
users) or untrusted (from external sources). When the agent proposes a tool call, \sys{}'s enforcement proxy
evaluates declarative policies that combine capability restrictions (risk tiers, tool allowlists), provenance
constraints (argument origins), scope limitations (path prefixes), temporal rules, and rate limits. Policies
can express nuanced rules like ``DENY file deletion IF arguments trace to untrusted sources AND target user
directories,'' enabling context-aware access control without relying on the LLM to make security decisions.

We evaluate \sys{} on a comprehensive benchmark of 100 attack scenarios and 20 benign tasks spanning direct injection, indirect injection via five vectors, encoding obfuscation, jailbreaks, and confused deputy attacks, deployed across four diverse LLM agent models (20B-120B parameters: GPT-OSS-120B, InternVL3.5-30B-A3B, Qwen3-30B-A3B, GPT-OSS-20B). \sys{} achieves \textbf{5.0\% attack success rate}---a \textbf{95\% reduction} compared to undefended systems and 40 percentage point improvement over state-of-the-art pattern filtering. Ablation studies reveal that provenance tracking contributes 20.9 pp ASR reduction beyond policy-only defense, validating our core insight that security requires tracking data origins, not just detecting patterns. \sys{} maintains \textbf{100\% task success rate} on benign operations with 0\% false positive rate and sub-2ms latency overhead. We release \sys{} as open-source software with complete benchmark suites and reproducible evaluation tools.
\end{abstract}
